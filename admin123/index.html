Para suas mudanças aparecerem em canais.obunker.pro, esta página precisa de uma chave do GitHub. Você faz isso uma vez em cada aparelho onde for editar.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Token name escreva agenda e escolha uma validade em Expiration.
  3. Em Repository access marque Only select repositories e escolha youtubeprojeto.
  4. Em Permissions › Repository permissions › Contents, escolha Read and write.
  5. Clique em Generate token, copie a chave e cole aqui embaixo.
